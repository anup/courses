SYS

You need Linux

Install Ubuntu on your laptop before the first class. A MacBook also works, since macOS already runs Unix commands. We compile with gcc in the terminal.

Who this course is for

ES248 is an elective, and it is beginner friendly. You do not need to know how to code. We start from the basics and spend a lot of time on them, so that everyone who registers can keep up. If you already code, you will still get plenty of practice: you will write and run C programs every week.

Topics

  • Linux basics — working in the terminal and compiling with gcc.
  • C basics — data types, variables, input and output, operators, conditions and loops.
  • Arrays and strings
  • Pointers and memory — addresses, pointer arithmetic, 2D arrays, malloc and free, function pointers, endianness.
  • Structures and unions
  • Time complexity — counting steps and Big O.
  • Linked lists, stacks and queues
  • BFS, DFS and backtracking — searching grids and graphs.
