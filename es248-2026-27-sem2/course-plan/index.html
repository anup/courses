Course Plan

ES248: Introduction to Data Structures and Algorithms. The bridge between Computing in Python and DSA 1 in C.

Why take this course

You learned to program in Python in ES 112/113. DSA 1 (ES242) is taught in C and expects you to be comfortable with it. ES248 fills the gap between the two.

ES 112/113 (Python)  →  ES248 (C + basic DSA)  →  DSA 1 (DSA in C)

If you have ever wondered what really happens when your Python code runs, this course shows you. Python hides memory, pointers and how data is laid out. In C you handle all of it yourself, so you see how data structures actually work on the machine.

Beginner friendly

This is an elective, and we want it to stay beginner friendly. A lot of the course is foundations: writing, compiling and fixing small C programs until they feel natural. If Python still feels shaky, you are welcome here. If you are already confident, you will still get plenty of practice: you will write C programs every week.

Who should take it

  • Students planning to take DSA 1 or other systems courses.
  • Anyone interested in systems programming, embedded systems or IoT.
  • Students preparing for technical interviews, many of which test C and how memory works.
  • Anyone curious about low-level programming and how a computer runs a program.

You need Linux

Install Ubuntu on your laptop before the first class. A MacBook also works, since macOS already runs Unix commands. Help with setup is given in the first lab.

What you will be able to do

  1. Write, compile and debug C programs on Linux.
  2. Explain how memory works: the stack and the heap, pointers, and malloc and free.
  3. Build linked lists, stacks and queues in C, using both arrays and pointers.
  4. Work out how the running time of a program grows with its input.
  5. Search a grid or graph with BFS and DFS.
  6. Start DSA 1 ready to work in C.

Topics

  • Linux basics — the command line, the filesystem, compiling with gcc.
  • From Python to C — compiling, types, input and output, conditions and loops.
  • Arrays and strings — how they sit in memory and what each operation costs.
  • Pointers and memory — pointer arithmetic, 2D arrays, dynamic memory, function pointers, endianness.
  • Structures and unions — your own data types and how they are laid out in memory.
  • Time complexity
  • Linked lists, stacks and queues
  • BFS, DFS and backtracking

How the course is taught

  • Lectures: concepts and live demonstrations, often comparing Python with C.
  • Labs and practice: hands-on coding every week, including online contests on sites such as CodeChef and AtCoder, solved in C.
  • Some topics may be flipped: watch a short video before class, then code during class.

Resources

  • Main resource: Charles Severance, C Programming for Everybody. Free online, and written for people who learned Python first.
  • Videos: mycodeschool playlists on C, pointers and data structures.
  • Books for reference: Kernighan and Ritchie, The C Programming Language; K. N. King, C Programming: A Modern Approach; Langsam, Augenstein and Tenenbaum, Data Structures Using C and C++.
  • Last offering: slides from Semester II, 2025-26.
