4. System Setup: Ubuntu + C Compiler

Ubuntu is the primary operating system for this course. Get it working on your laptop today — ask for help in the lab if anything fails.

Windows

Install WSL (Windows Subsystem for Linux), which gives you Ubuntu inside Windows. Open PowerShell as Administrator and run:

wsl --install

Restart when asked, open the Ubuntu app, create a username and password, then follow the Ubuntu instructions below inside the Ubuntu terminal.

Ubuntu / other Linux

sudo apt update
sudo apt install build-essential

macOS

xcode-select --install

On macOS the gcc command runs Apple's Clang compiler. That is fine for this course.

Verify

gcc --version

If this prints a version number, you are done.

6. First C Program

Create a file named hello.c in your es248 folder, using any editor (VS Code recommended):

#include <stdio.h>

int main(void) {
    printf("Hello, ES248!\n");
    return 0;
}

Compile and run it:

gcc hello.c -o hello
./hello

Unlike Python, there are two steps: gcc translates your source file into an executable, then you run the executable. We will spend real time on what happens in between.
