Heap Sort

A binary heap is a complete tree stored in a plain array, where every parent outranks its children. Build a max-heap in O(n), then repeatedly swap the root to the end and sift down what is left. That gives an in-place O(n log n) sort — and the same heap is the priority queue behind many other algorithms.

Practice — heaps and priority queues

Start with the smallest heap operations, then use a heap as a tool: keep the top-k, or merge many sorted streams. Contrast 215 here (heap of size k) with the quickselect version from Class 05.

  • 1046. Last Stone Weight — a max-heap, pop the two biggest, push the difference.
  • 703. Kth Largest Element in a Stream — keep a min-heap of size k as numbers arrive.
  • 215. Kth Largest Element — solve it again with a size-k heap; compare with quickselect.
  • 347. Top K Frequent Elements — count, then heap the counts.
  • 23. Merge K Sorted Lists — a min-heap over the list heads.
  • Paper trace: take an array of length 6–8. Build a max-heap by sifting down from the last parent, then run the sort — swap root to the end, shrink, sift down — recording the array after each step.
