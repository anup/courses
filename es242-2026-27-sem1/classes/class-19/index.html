Depth-First Search

Explore a graph the way a mouse explores a maze: go as far as you can along one path, and back up only when there is nowhere new to go. Then use the DFS tree it builds to classify edges, detect a cycle in a directed graph, and put the vertices of a directed acyclic graph in topological order.

What the material covers

  • The algorithm — DFS(u): mark u visited, then for each unvisited neighbour v of u, call DFS(v). The recursion is the mouse backing up. Each vertex is visited once and each adjacency list scanned once, so DFS takes O(n + m) with an adjacency list.
  • What DFS gives you — DFS does not find shortest paths; use BFS for that. It does tell you which vertices are reachable from the source, so it checks whether a graph is connected.
  • The DFS tree — join each vertex to the vertex whose call discovered it. If the graph is not connected, start a new DFS from each vertex that is still unvisited, in order; you get one tree per start.
  • Non-tree edges in a directed graph — draw the trees and sibling subtrees left to right in the order they were discovered. Every other edge is a forward edge (to a descendant), a back edge (to an ancestor) or a cross edge from right to left. A cross edge from left to right cannot exist: DFS would have followed it.
  • Non-tree edges in an undirected graph — forward and back edges are the same thing, and cross edges cannot exist. Every non-tree edge is a back edge.
  • Cycle detection in a directed graph — a directed graph has a cycle exactly when DFS finds a back edge. Keep three states per vertex: 0 = not started, 2 = DFS running (on the call stack), 1 = DFS finished. An edge to a vertex in state 2 is a back edge. No tree needs to be built.
  • Topological sort, by removing vertices — in a directed acyclic graph, repeatedly take a vertex with indegree 0, append it to the order, and remove it with its outgoing edges. With indegree counts and a queue this runs in O(n + m).
  • Topological sort, by DFS — record each vertex in finish[] when its DFS call ends. A vertex finishes only after everything it can reach, so the reverse of the finishing order is a topological order.

Practice route

  1. Write DFS: LeetCode 733 (Flood Fill), then LeetCode 200 (Number of Islands).
  2. The DFS tree on a rooted tree: Codeforces 580C (Kefa and Park).
  3. Cycles: CSES Round Trip (undirected), then CSES Round Trip II (directed, the three-state DFS).
  4. Topological sort: CSES Course Schedule, solved once with indegrees and once with the DFS finishing order.
  5. Extension: dynamic programming in topological order, CSES Longest Flight Route.
