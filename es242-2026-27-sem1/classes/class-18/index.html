Breadth-First Search

Find the shortest path from a source to every vertex of an unweighted graph by discovering vertices one distance at a time, with a queue to keep them in order. Then use the BFS tree it builds to test whether a graph is bipartite, count connected components, move a knight across a chessboard, and check whether a directed graph is strongly connected.

What the material covers

  • Shortest paths in an unweighted graph — the source is the only vertex at distance 0. Using all the vertices at distance i−1, find every vertex at distance i. Set a vertex's distance only the first time you discover it; never change it afterwards.
  • The queue — as soon as you set a vertex's distance, add it to the queue, and process the queue in order until it is empty. Vertices then come out at distance 0, then 1, then 2. Each vertex enters the queue once, so an array of size n with two indices, first and last, is enough. distance[v] = -1 marks a vertex not yet discovered.
  • Running time — processing vertex u scans its d(u) neighbours. Summed over all vertices this is O(n + m), with an adjacency list.
  • The BFS tree — join each vertex to the vertex that discovered it. Level i of the tree holds the vertices at distance i. For every edge (u, v), tree or not, the levels of u and v differ by at most 1.
  • Bipartite graphs — split the vertices into two sets so every edge crosses between them. Run BFS: the graph is bipartite exactly when no edge joins two vertices on the same level, that is, when no edge has distance[u] == distance[v].
  • Connected components — a BFS from one vertex reaches only its own component. Start a new BFS from each vertex that is still undiscovered and count the BFS trees.
  • Implicit graphs: knight moves — each square (i, j) of an n × n board is a vertex, and its neighbours are the up to 8 squares a knight can jump to. Generate them on the fly with two displacement arrays and a bounds check; the queue holds pairs (i, j).
  • Strongly connected graphs — a directed graph is strongly connected if every vertex can reach every other. A BFS from each vertex costs O(n(n + m)). Instead, run one BFS from s in the graph and one from s in the reversed graph: if both reach every vertex, any u can reach v through s.
