Augmenting Data Structures

Store extra information in a data structure so it can answer a new query quickly. The extra field must remain correct after every update. Start with the minimum in a stack, add counts to a BST, then store summaries of array intervals in a segment tree.

The 116-slide deck traces the added fields and the paths used by each query. Slides 2–10 cover min-stacks, 11–41 cover augmented BSTs, and 42–116 cover segment trees.

What the material covers

  • Min-stack — store the minimum of the stack prefix at each node. The top node then answers getmin in O(1), while push and pop also take O(1). Popping restores the previous minimum automatically.
  • K-th smallest in a BST — lessThanNum stores the number of nodes in the left subtree. Compare k with that count plus one to choose a single branch. Selection takes O(h), rather than visiting the whole tree.
  • Maintaining counts — update ancestor counts when inserting or deleting. For deletion with two children, account for the successor that is physically removed. The slides assume distinct keys.
  • Rank and range counts — count keys strictly less than x even when x is absent. For an inclusive range [x, y], subtract the number below x from the number at most y.
  • Range minimum and range sum — a segment tree stores an interval summary at each node. Build in O(n), use O(n) space, and combine O(log n) pieces for each query. The slides use an array layout with children at 2*i+1 and 2*i+2.
  • Range addition and point reporting — store additions on nodes covering the updated interval. Report a value by accumulating the additions along its path, including the root. Both operations take O(log n).

The BST bounds are O(h). They become O(log n) only when the tree's height stays logarithmic. The array segment tree is balanced by construction.

Practice route

  1. Implement the lecture min-stack, then solve LeetCode Min Stack or HackerRank Maximum Element.
  2. Revisit k-th smallest using subtree counts, then add findLessThan and the lecture's inclusive range-count homework.
  3. Solve CSES Static Range Minimum Queries and Static Range Sum Queries with your own segment tree.
  4. Solve CSES Range Update Queries, matching the deck's range-add and point-report operations.
