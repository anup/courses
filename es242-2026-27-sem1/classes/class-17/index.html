Graphs

A graph is a set of vertices and a set of edges between them. Read a graph from an edge list and store it so you can list a vertex's neighbours quickly. Then count simple structures: degrees, two-way pairs, triangles and paths of length two.

What the material covers

  • Input format — the first line gives n m, the number of vertices and edges. Each of the next m lines gives one edge as two vertex numbers. Vertices are numbered 0 to n−1.
  • Adjacency matrix — an n × n array of 0s and 1s. It is easy to write, and checking whether an edge exists takes O(1). It always uses O(n2) space, and listing a vertex's neighbours takes O(n), even when the vertex has few.
  • Adjacency list — an array of n linked lists; list i holds the neighbours of vertex i. It uses O(n + m) space and lists the neighbours of v in O(d(v)), where d(v) is the degree of v. It is harder to write, and checking whether an edge exists means scanning a list.
  • A 2D array with a degree count — row i stores the neighbours of i, and degree[i] records where the row ends. It is easy to write but wastes space, because every row must be as long as the largest degree.
  • Directed graphs — each edge goes from one vertex to another. Store only the forward edge, and keep separate out-degree and in-degree counts.
  • Two-way pairs — in a directed graph, count unordered pairs {u, v} where both u→v and v→u exist. Count each pair once.
  • Triangles — in an undirected graph, count sets of three vertices with all three edges present. The sample graph has two.
  • Paths of length two — count paths u—v—w, treating u—v—w and w—v—u as the same path. Report the count mod 5, in O(n + m) time. The count can overflow an int, so reduce as you add: (a + b) mod 5 = (a mod 5 + b mod 5) mod 5.

Practice route

  1. Store a graph both ways: AtCoder ABC343 B (Adjacency Matrix), then ABC276 B (Adjacency List), where n reaches 100,000 and a matrix will not fit.
  2. Count degrees: AtCoder ABC061 B (Counting Roads), then LeetCode 1791 (Find Center of Star Graph).
  3. Use in-degree and out-degree: LeetCode 997 (Find the Town Judge).
  4. Count triangles: AtCoder ABC262 B (Triangle (Easier)), then Codeforces 574B (Bear and Three Musketeers).
