Running Time and Big-O Notation

Why we measure running time on the worst-case input, and how Big-O gives a machine-independent way to compare algorithms.

What We Covered

  • Running time is machine-dependent; the same program takes different wall-clock time on different machines.
  • We define the running time of an algorithm as its running time on the worst-case input.
  • Big-O drops lower-order terms and constant factors, leaving a machine-independent measure of how running time grows with input size.
  • Using Big-O to decide which of two algorithms is better for large inputs.
