Arrays, Pointers & Structures

A second pass over pointers, then structures. When sum(a, b) runs it gets copies, which is why a function cannot change its caller's variable and why scanf needs &a. Arrays are the exception: pass one and nothing is copied, because the function receives a pointer to the first element. From there, memory you manage yourself — malloc, free, and an array sized only when the input arrives. The class ends by gluing several fields into one type, struct Person, which is what Class 10 needs to build a list.

What the class covered

  • Pass by value — the parameters are copies, not the caller's variables.
  • Arrays are the exception — A is a pointer to num[0], so the function reads your array directly. A pointer carries no length, hence the separate n.
  • Four ways to write one function — int A[] or int *A, A[i] or *(A+i). All compile to the same thing.
  • Reverse with two pointers — from the ends, walking inward, swapping. The swaps land in the caller's array.
  • Returning an array — a local dies when the function returns; malloc fixes it, and the caller then owes a free.
  • Growing an array — add() allocates one bigger, copies, appends. In a loop that reads input of unknown length.
  • Structures — struct Person groups name, age and salary. Passing by value copies all of it; pass &p1 and reach fields with p->name, which is shorthand for (*p).name.
  • Arrays of structs — the same add and removeAt patterns, with struct Person in place of int.

Practice

The exercises posed in class. No judge — write them, run them, and make sure every malloc has exactly one free.

  • void reverse(int *A, int n) — in place, two pointers. Check main's array actually changed.
  • int *add(int A[], int n, int num) — a new array one longer, original untouched.
  • Read positive integers until -1 and print them in reverse, growing the array as you go. Order matters inside the loop: allocate, then free the old block, then reassign.
  • int *removeAt(int *arr, int n, int index) — two pointers walk in step; on the removed index only the source advances.
  • On the judge: the malloc problems on the practice page — same allocate, fill, return shape as add, but marked for you.
  • The employee record. Commands one per line until -1: 0 <name> adds a person, 1 <index> removes one. Reuse add and removeAt with struct Person — almost nothing else changes, which is the point. Handle the empty record and an out-of-range index.
