Tree Traversals

Inorder, preorder and postorder change when the node is visited. Use traversal order to check a BST, find its k-th smallest value, reconstruct a tree, and combine child results to solve height, diameter and coloured-tree problems.

Topics in the shared deck

  • Three traversal orders — inorder is left, node, right; preorder is node, left, right; postorder is left, right, node. Each takes O(n) time.
  • Inorder in a BST — distinct keys appear in increasing order. Use this to validate a BST and find the k-th smallest value.
  • Reconstruction — with distinct values, inorder plus preorder or postorder determines the tree. Preorder plus postorder alone does not uniquely determine a general binary tree.
  • Height — combine child heights after visiting both children. The slides count edges: empty subtree -1, leaf 0.
  • Diameter — return subtree height while tracking the longest path through each node. The diameter may lie entirely below the root.
  • Coloured subtrees — return yellow-minus-red counts to classify subtrees, then find the smallest connected subtree containing all yellow nodes.

Practice

Work through inorder, preorder and postorder first, then BST applications, reconstruction, height and diameter. Finish with the coloured-tree exercises from the slides.
