Binary Search Trees

Keep a set of numbers that changes as you insert and delete elements. In a binary search tree, every node separates smaller values on the left from larger values on the right. A comparison tells you which branch to follow. Search, insertion and deletion take O(h) time, where h is the tree's height. A short tree makes these operations fast; a tree that grows into a chain can still take O(n).

What the class covered

  • A binary tree in C — a struct node stores an integer and two pointers, left and right. makenode allocates a node and sets both child pointers to NULL. An empty tree has root == NULL.
  • The BST rule — every value in a node's left subtree is smaller than its value; every value in its right subtree is larger. This applies to whole subtrees, not just immediate children. The slides assume distinct values.
  • Insertion — follow comparisons until the new value belongs at an empty child link, then attach the new node. Inserting into an empty tree changes root.
  • Search — follow the same comparisons. Finding the value returns 1; reaching NULL returns 0.
  • Deleting a leaf or a node with one child — find the node and its parent, then replace the parent's link with NULL or the surviving child. Deleting the root needs to update root. Free the removed node.
  • Deleting a node with two children — find its inorder successor, the smallest value in its right subtree. Copy that value into the node, then remove the successor. The successor has no left child; its right child, if present, must stay connected.
  • Height determines the cost — these operations follow paths through the tree and take O(h). A balanced tree has height O(log n), but the insertion algorithm here does not keep the tree balanced.

Build and trace it in C

Write makenode, insert, search and delete from the slides before moving to the judge. Draw the links that each operation changes.

  • Insert 4, 2, 9, 5, 6 into an empty tree. Search for 6 and 7, listing the nodes visited in each search.
  • On fresh copies of that tree, delete 2 (a leaf), 5 (one child), and 4 (the root, with two children). Also try deleting a missing value and deleting the only node in a tree.
  • Insert 10, 4, 15, 12, 13, then delete 10. Its successor is 12, which has a right child. Check that 13 is still reachable afterward.
  • Insert 1, 2, 3, 4, 5, 6, 7 in that order, then compare with 4, 2, 6, 1, 3, 5, 7. Search for 7 in both. The same values can produce very different heights.

LeetCode practice

Start with the three operations from class, in this order. Use C and keep track of which function can change the root.

  1. 700. Search in a Binary Search Tree — Easy. The same search path as in the slides, but return the matching node rather than 1 or 0.
  2. 701. Insert into a Binary Search Tree — Medium. Allocate and attach the new node; return the root, including when the original tree was empty.
  3. 450. Delete Node in a BST — Medium. Work through all three deletion cases and return the possibly changed root.

Then try 98. Validate Binary Search Tree to check your understanding of the rule for whole subtrees.
