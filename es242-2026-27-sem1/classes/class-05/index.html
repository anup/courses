Quick Sort

Another divide-and-conquer sort, but the work happens before the recursion, not after. Pick a pivot, partition the array so smaller elements sit left and larger sit right, then sort each side. Average case is O(n log n); a bad pivot gives O(n²), which is why pivot choice matters.

Practice — quick sort and partitioning

The heart of quick sort is partition. These build from writing the sort itself to using partition on its own to answer a question without finishing the sort. Full topic list on the practice page.

  • 912. Sort an Array — submit your own quick sort here.
  • 75. Sort Colors — three-way partition (Dutch National Flag) in a single pass.
  • 215. Kth Largest Element — quickselect: partition, then recurse into only one side.
  • 973. K Closest Points to Origin — quickselect again, on a computed key.
  • Paper trace: take an array of length 6–8. Run partition with the last element as pivot and write the array after every swap, then recurse on each side until sorted.
