Pointers in C

Every variable sits somewhere in memory, and that somewhere has a number. &x hands you the number; *p goes back to it. Once you have both, a function can change a caller's variable — which is what scanf has been doing with &a since Class 02. The rest follows: an array passed to a function is a pointer to its first element, so A[i] is shorthand for *(A+i). Then lifetime — a local dies when its function returns, so returning its address is a bug, and malloc is the fix.

  • Snippet 8 — a function assigns to A[1] and the caller's array changes. Nothing was copied.
  • Snippet 11 — +1 moves an int* by 4, a char* by 1. Pointer arithmetic counts elements, never bytes.
  • Snippet 21 — returning the address of a local array. The compiler warns; the pointer dangles the moment the function returns.
  • Snippet 31 — why int* p, q; does not declare two pointers.

Practice

LeetCode has no pointers category and cannot have one — the judge checks your return value, so it tests what pointers let you do, not the syntax. Solve these in C using pointers rather than indices, even where indices would be easier. Linked lists in Class 10 are where the judge really exercises pointer manipulation. Full list on the practice page.

  • 344. Reverse String — snippet 17's two-pointer reverse, on a char array.
  • 125. Valid Palindrome — the same walk, comparing instead of swapping.
  • 167. Two Sum II — ends inward on a sorted array.
  • 283. Move Zeroes — read and write pointers at different speeds.
  • 27. Remove Element — copy and skip, in place.
  • 11. Container With Most Water — harder: why is moving the shorter side safe?

And these in C, with no judge — this is where malloc and free actually get practised:

  • void swap(int *a, int *b), then use it to shorten snippet 17's reverse.
  • void min_max(int *A, int n, int *min_out, int *max_out) — returning two answers through pointer parameters.
  • Fix snippet 21 so create() returns an array the caller can use and free.
  • Run a malloc program without its free. On macOS, leaks -atExit -- ./a.out shows what you lost.
