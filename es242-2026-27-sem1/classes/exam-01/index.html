First Graded Exam: Instructions

C programming on the lab's Ubuntu systems, submitted through DOMjudge. Read the workflow below before you come.

Before the Exam

DOMjudge does not have an online code editor. You must write, save, compile, and test your C program locally before uploading the main.c source file.

Use the practice contest to complete this full workflow at least once before the exam.

Write and Test Your Program

  1. Create a folder for your work, for example Documents/ES242.
  2. Open VS Code or Sublime Text and save your C program in that folder as main.c.
  3. Open Terminal, move to the folder, and compile the saved file.
cd ~/Documents/ES242

gcc -std=c11 main.c -o main
  1. Run the compiled program and test it with the sample input from the problem.
./main

# Or, if you saved sample input in input.txt:
./main < input.txt

Fix any compilation errors or incorrect output locally before submitting.

Submit to DOMjudge

  1. Log in to DOMjudge using the credentials provided for the exam.
  2. Open the correct problem and choose Submit.
  3. Select the correct problem and choose C as the language.
  4. Upload your saved source file: main.c.
  5. Check the verdict. If it is not accepted, correct your local source file, compile and test again, then resubmit.

Important

  • DOMjudge does not provide an online editor. Write and save your program locally first.
  • Upload the C source file (.c), not the compiled main binary.
  • Save your work frequently and submit well before the contest closes.
  • Use only your assigned machine and your own DOMjudge account.
  • Ask a proctor if the machine, editor, compiler, or DOMjudge page is not working.
