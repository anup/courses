Queues

Numbers arrive one at a time. After each one, report the earliest number that has so far appeared exactly once. A frequency array tells you how often each number has appeared, but not which single-appearance number came first; rescanning the stream after every arrival costs O(n) each time. Instead, keep the candidates in arrival order. New numbers join at the back. The answer is always at the front, once you throw away any front number that has since repeated. A stack serves the newest element first; this problem needs the oldest. That is a queue.

What the class covered

  • The problem — first non-repeating number in a stream. Numbers lie between 0 and n-1, and -1 ends the stream. Print -1 when no number has appeared exactly once.
  • Frequency array — frequency[num]++ on each arrival. That answers “how many times?” in O(1), but not “which came first?”
  • The queue of candidates — enqueue a number the first time it appears, when its frequency becomes 1. A repeat only raises its count; it is not added again.
  • Finding the answer — while the front number's frequency is above 1, dequeue it. What is left at the front is the answer. If the queue empties, the answer is -1.
  • Why it is fast — each number is enqueued at most once and dequeued at most once. The whole stream costs O(n), even though one arrival may trigger several dequeues.
  • Queue in a linked list — two pointers: first for removing, last for adding. enqueue links a new node after last; dequeue removes the node at first and frees it. Both O(1).
  • The empty-queue cases — enqueueing into an empty queue must set both first and last. Dequeueing the only node must set both back to NULL, or last keeps pointing at freed memory.

Trace the stream 5 1 5 1 -1 by hand, writing down the frequency array and the queue after each number. The answers should be 5, 5, 1, -1.

Practice

Write the queue in C first, with malloc and free. The judge problems below let you use whatever you like, so they skip the pointer work.

  • enqueue and dequeue from the slides, plus the stream program built on them. Test with a queue that empties and refills several times.
  • A queue in an array. Where do first and last go when they reach the end of the array? Wrap them around with %, and work out how to tell a full queue from an empty one.
  • Why not use one pointer, as the stack did? Try enqueue with only first and count the steps.
