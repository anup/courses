LeetCode problems for each topic we cover in class, in the order we cover it. Each class page links here to its own section. New topics are added as we reach them.

Running time & Big-O Class 01

The point of each problem: write the obvious solution first, state its Big-O, then find a faster one and say why it is faster.

  • 1480. Running Sum of 1d Array — a clean O(n) pass.
  • 217. Contains Duplicate — O(n²) brute force vs an O(n) set.
  • 1. Two Sum — nested loops vs a hash map.
  • 121. Best Time to Buy and Sell Stock — O(n²) vs one pass.
  • 53. Maximum Subarray — brute force vs Kadane's O(n).
  • 268. Missing Number — a sum formula in O(n) vs sorting in O(n log n).
  • 704. Binary Search — O(log n) instead of scanning all n.

Arrays & insertion sort Class 03

In-place array work and the shifting idea at the heart of insertion sort.

  • 147. Insertion Sort List — insertion sort, spelled out.
  • 26. Remove Duplicates from Sorted Array — in-place, two pointers.
  • 283. Move Zeroes — stable shifting, like an insertion pass.
  • 88. Merge Sorted Array — merge in place from the back.
  • 1752. Check if Array Is Sorted and Rotated — reason about sorted order in one scan.
  • 485. Max Consecutive Ones — a simple array scan with a running count.
  • 912. Sort an Array — submit your own insertion sort.

Merge sort Class 04

The merge step, end to end, then merge sort itself — on arrays and on lists.

  • 88. Merge Sorted Array — the merge step on its own.
  • 21. Merge Two Sorted Lists — the same merge, on linked lists.
  • 148. Sort List — merge sort on a linked list.
  • 23. Merge K Sorted Lists — generalises the two-list merge.
  • 912. Sort an Array — submit your merge sort here.
  • 315. Count of Smaller Numbers After Self — hard: count inversions during the merge.

Quick sort & partitioning Class 05

Partition is the engine. Build from writing the sort to using partition alone to answer a question.

  • 912. Sort an Array — submit your own quick sort.
  • 75. Sort Colors — three-way partition (Dutch National Flag).
  • 215. Kth Largest Element — quickselect: partition, recurse into one side.
  • 973. K Closest Points to Origin — quickselect on a computed key.

Heaps & priority queues Class 06

From the smallest heap operations to using a heap as a tool: keep the top-k, or merge many sorted streams.

  • 1046. Last Stone Weight — a max-heap, pop two, push the difference.
  • 703. Kth Largest Element in a Stream — keep a min-heap of size k.
  • 215. Kth Largest Element — heap of size k; compare with quickselect above.
  • 347. Top K Frequent Elements — count, then heap the counts.
  • 23. Merge K Sorted Lists — a min-heap over the list heads.
