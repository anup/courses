Class 16 · Monday 12 October

Agent Golf

In Class 07 you counted the tokens in one prompt and one answer. Today an agent does the whole job: it reads, runs commands, reads the output and tries again. Every token in that run counts, including the agent's own reading. Solve a Hackattic problem with the Pi coding agent, then do it again with fewer tokens.

1. Set up (once, 15 minutes)

On Windows, install Git for Windows first and type every command below in Git Bash, not PowerShell.

  1. Install Pi.

    macOS or Linux:

    curl -fsSL https://pi.dev/install.sh | sh

    Windows: there is no installer script, so Pi comes from npm.

    1. Install Git for Windows. Pi runs the agent's commands in its Git Bash.
    2. Install Node.js, version 22.19 or newer (the LTS download is fine). Keep the installer's option that adds Node to your PATH.
    3. Open Git Bash (from the Start menu) and run: 
      npm install -g --ignore-scripts @earendil-works/pi-coding-agent

    The same npm command also works on macOS or Linux if you already have Node.js 22.19 or newer.

    Check it with pi --version. If Windows says pi is not found, close Git Bash and open it again.

  2. Install the golf plugin. 
    pi install npm:agent-golf@preview
    Check that it landed where the start command in section 2 looks for it; this should list package.json: 
    ls ~/.pi/agent/npm/node_modules/agent-golf
  3. Register at agent-golf.csbasics.in/register with a username and your Hackattic username. The page shows your secret key once. Save it somewhere private.
  4. Have your two secrets ready, and never type them into a prompt. Your whole session is uploaded when you submit, and anything you type goes with it.
    • OpenRouter key: openrouter.ai/settings/keys. If you committed one earlier this semester, make a new one today. You give it to Pi once, with /login (section 2), not as an environment variable: the agent's commands run in your terminal and could print it.
    • Hackattic token: shown on any challenge page when you are logged in to hackattic.com. The agent needs this one, so put it in the terminal you start Pi from: 
      export HACKATTIC_TOKEN=your-hackattic-token
      Tell the agent the token is in $HACKATTIC_TOKEN.

2. Start every attempt the same way

Each attempt is a new, empty folder and a new Pi session. Do both steps every time.

First, a new empty folder:

mkdir -p ~/golf/try-1 && cd ~/golf/try-1

Then start Pi in it:

AGENT_GOLF_API_BASE_URL=https://agent-golf.csbasics.in pi \
  --model openrouter/nvidia/nemotron-3-super-120b-a12b:free \
  --no-extensions -e ~/.pi/agent/npm/node_modules/agent-golf \
  --no-skills --no-context-files --no-mcp --no-prompt-templates

Change try-1 each time (try-2, try-3…). The flags load nothing but Pi and the golf plugin. That matters: an agent with extra tools and skills carries them into every turn. In our test, the same one-word reply cost 1,211 tokens with this command and 14,005 tokens with a Pi full of add-ons.

The model is your choice. The one above is free on OpenRouter and handled a small test task cleanly. Gemma, which we used in Class 07, was being refused by its provider when we tested this morning, because everyone shares its free capacity. Other free models that worked: openrouter/cohere/north-mini-code:free and openrouter/poolside/laguna-s-2.1:free. Pick one and keep it for the whole session: replies from two models unrank the attempt.

Free models have a daily limit. An OpenRouter account that has never bought credit gets 50 free-model requests a day and 20 a minute, shared across all free models. Every agent turn is one request, so a long, wandering attempt can use up your day, and switching to another free model will not help. Plan each attempt before you start it. (An account that has bought $10 of credit gets 1,000 a day.)

The first time, inside Pi, give it your OpenRouter key: type /login, choose OpenRouter and paste the key. Then log in to the board with the key from step 3:

/golf-login your-secret-key

/golf-problems shows the rules and both problems. None of these commands costs a token.

3. The problems

ProblemWhat the agent must doNote
Help me unpack
help_me_unpack		 Fetch a base64 string, unpack the numbers packed in its bytes, send them back. Start here. Most of you solved it in Class 08. Today the question is not whether you can solve it, but how cheaply.
Brute force ZIP
brute_force_zip		 Download a password-protected ZIP, find the password (4 to 6 lowercase letters or digits), read secret.txt, send it back. Very hard; try it only after Help me unpack. Nobody in the class has solved it. The problem expires 30 seconds after the fetch, and a Python search over 6-character passwords is far too slow: the one solve we have ran a compiled C program on several cores, and took over 200,000 tokens. Windows Git Bash has no C compiler.

4. The rules

  1. One attempt is one new Pi session in a new, empty folder, started with the command in section 2. Runs with other add-ons do not count. Try as often as you like; your best solved attempt counts.
  2. Solve from scratch. No code from an earlier attempt or from your Class 08 repo, and do not point the agent at it.
  3. Prompts in plain English. No code pasted in, and no ! commands of your own: only the agent runs commands.
  4. The agent's program must fetch the problem from hackattic.com, submit the answer there, and print both of Hackattic's replies. The board counts a solve only when that printed reply says "result": "passed".
  5. Stop as soon as Hackattic says passed. Everything in the session counts: wrong answers, dead ends, retries.
  6. Fewest total tokens wins. Ties go to fewer prompts, then fewer characters typed.
  7. Unusually low scores may be asked to repeat the run in front of us.

5. Spending fewer tokens

Every turn sends the whole conversation back to the model. A short prompt that leaves the agent to explore costs more than a precise one, because the exploring is paid for again on every later turn.

  • Read the challenge page yourself first. You know what the agent would otherwise spend tokens finding out.
  • Say exactly what you want: the endpoint, the format, and one script that fetches, solves, submits and prints both replies.
  • Ask for no explanations. Stop the agent the moment it starts reading things it does not need.
  • Watch what the commands print. A command that prints a whole page costs every line of it.

6. Submit

In the same Pi session, after Hackattic says passed:

/golf-submit help_me_unpack

or, for the ZIP problem:

/golf-submit brute_force_zip

Confirm, and Pi shows your tokens and a link to your entry. Resubmitting the same session replaces it.

Closed Pi before submitting? Go back into that attempt's folder and run the section 2 start command again with --continue added at the end. It reopens your last session there; then /golf-submit. Reopening costs no tokens. The board is at agent-golf.csbasics.in.

"Unranked" lists the reason. If Hackattic said passed but the board says "not solved", keep that session folder and tell an instructor: the checker is new, and we will read the log ourselves. The "custom setup" warning appears for everyone today and does not affect your rank.

7. Before you leave

In your own repo, lab-notes/class-16.md, in "I": the model you used, your best token count for each problem you solved, the one thing that cost the most tokens, and the change that cut the most.
