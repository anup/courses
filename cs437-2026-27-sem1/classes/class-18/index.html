Class 18 · Tuesday 27 October

Agent Golf Exam

One new Hackattic problem, 75 minutes, GitHub Copilot Auto only. Solve it with the Pi coding agent, alone, from an empty folder.

1. Who can sit

Only students who have solved both Class 16 problems on the board (Help me unpack and Brute force ZIP) before the exam starts. If you have not, finish both first; you can then sit the second sitting later this week. There is no sitting from home.

2. Before it starts (5 minutes)

  1. Update the golf plugin, then close and reopen Pi: 
    pi update --extensions
  2. Put your Hackattic token in the terminal you start Pi from: 
    export HACKATTIC_TOKEN=your-hackattic-token
  3. Make a new, empty folder for your first attempt and start Pi exactly as in Class 16: 
    mkdir -p ~/golf/exam-1 && cd ~/golf/exam-1
AGENT_GOLF_API_BASE_URL=https://agent-golf.csbasics.in pi \
  --no-extensions -e ~/.pi/agent/npm/node_modules/agent-golf \
  -e ~/.pi/agent/npm/node_modules/pi-github-copilot-auto \
  --no-skills --no-context-files --no-mcp --no-prompt-templates
  4. In Pi: /model and pick GitHub Copilot Auto. Then /golf-login your-secret-key.

3. The problem

Tonight, Friday 30 October, 7:00–8:30 pm: Basic face detection. Read its page on Hackattic yourself before you prompt. Submit with /golf-submit basic_face_detection. Live ranking: agent-golf.csbasics.in/problems/basic_face_detection.

It needs OpenCV: the agent can install it with pip install opencv-python, which may take a minute.

Tuesday 27 October: Touch-Tone dialing (/golf-submit touch_tone_dialing); see the results.

4. Rules

Time75 minutes (tonight: 7:00–8:30 pm). Make as many attempts as you like to improve your score; only attempts submitted during the exam count.
ModelGitHub Copilot Auto only. An answer from any other provider anywhere in the session leaves the attempt unranked.
AloneYour own laptop, your own session, your own keys. No talking, no sharing prompts.
AttemptsAs many as you like; your best solved attempt counts. Each one is a new, empty folder and a new Pi session. Once you have solved it, Hackattic rejects further answers unless the solve URL ends in &playground=1 (…/solve?access_token=<token>&playground=1). Put that in your prompt for every attempt after your first solve; the board accepts "passed (playground mode)".
From scratchNo code, files or programs from earlier attempts, earlier classes or anyone else. Do not point the agent at them.
PromptsPlain English. No code pasted in, and no ! commands of your own: only the agent runs commands.
ProofThe agent's program fetches the problem from hackattic.com, submits the answer there, and prints both of Hackattic's replies. It counts only when that printed reply says "result": "passed".
SubmitIn the same Pi session, /golf-submit followed by the problem's name as the board shows it.
ChecksAn unusually low score may be asked to repeat the run in front of us.
