Week 1 Student Handout

Setup + First AI-Assisted Game

Set up the course infrastructure, create a private GitHub repository, and build a tiny browser game with an AI coding assistant.

Today's Goals

  1. Set up GitHub, GitHub Education, Copilot, and your private course repository.
  2. Build a tiny browser game using an AI coding assistant, then inspect and improve what it produces.

This course is not about blindly accepting AI-generated code. You are responsible for understanding, testing, debugging, and explaining the code you submit.

1. Fill The Course Form

Open the setup form in a browser where you can log in with your IITGN Google account.

Open CS437 Setup Form

You will be asked for your GitHub username, private course repository URL, GitHub Education status, Copilot status, short self-ratings, and collaboration notes. The form auto-detects your IITGN email. Do not share passwords, tokens, SSH keys, or personal credentials in the form.

2. GitHub Education And Copilot

Use the same GitHub account for GitHub Education, Copilot Student, your private course repository, and VS Code Copilot sign-in.

Apply For GitHub Education

  1. Log into GitHub.
  2. Add and verify your IITGN email address.
  3. Make sure your GitHub profile or billing name matches your institute document.
  4. Apply for GitHub Education Student benefits.
  5. If approved, activate GitHub Copilot Student from the Education benefits page.

If your application is still pending today, continue with the rest of the lab. Pending status is okay for Week 1.

3. VS Code And Copilot Setup

  1. Open Visual Studio Code.
  2. Click the Accounts icon in the bottom-left corner.
  3. Sign in with the GitHub account used for GitHub Education.
  4. Click the Copilot icon in VS Code.
  5. Enable or sign in to Copilot if asked.
  6. Open Copilot Chat and check whether it responds.

If Copilot says subscription not found, check whether GitHub Education is approved, Copilot Student is activated, VS Code is signed into the correct GitHub account, and browser authorization did not happen with a different GitHub account.

4. Optional Tool: Antigravity

Antigravity is optional for this course. If you have access, sign in with your Google/IITGN account and use it for comparison with Copilot. All graded work must still be committed to your GitHub repository.

7. First AI-Assisted Coding Task: Bug Dodger

Create a simple browser game using HTML, CSS, and JavaScript. Use this prompt with Copilot Chat, Antigravity, Gemini, or another AI coding assistant:

Create a simple browser game called Bug Dodger using only HTML, CSS, and JavaScript.

Rules:
- The player controls a square at the bottom of the screen.
- Bugs fall from the top.
- The player moves left and right using arrow keys.
- If a bug hits the player, the game ends.
- The score increases over time.
- Add a restart button.
- Keep the files as index.html, style.css, and game.js.
- Explain how to run it locally.

Put the files in games/week-01/. Run the game by opening games/week-01/index.html in a browser.

8. Review The AI Output

After the first version works or partially works, ask the AI:

Review this game code. Find at least five possible bugs, missing edge cases, or design problems. Do not rewrite yet.

Then ask:

Fix the top three issues while keeping the code simple enough for a beginner to understand.

Do not accept changes blindly. Read the code and run the game again.

9. Update Your AI Log

In lab-notes/week-01.md, record which tool you used, your original prompt, what files the AI created, what worked, what broke or was unclear, what you changed manually, how you verified the game, and one thing you still do not understand.
