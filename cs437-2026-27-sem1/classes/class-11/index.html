3. Your track

A — you cleared it

Write a tester: takes an address, a port and a record set, reports what fails. Run it for two people in Track B. Report failures only — do not fix them, do not say where to look.

A correct server, whatever records it holds:

  • answers from a different machine
  • answers with and without a trailing dot
  • answers the type asked, not another type it holds for that name
  • returns no such name for a name it lacks — not silence
  • still answers on the tenth query
  • serves a wildcard, if the set has one

Commit as hackattic/serving_dns/conformance.py.
