Prompt Golf

Yesterday the rule was "explain, don't drive." Today it flips: the AI writes the code, and your skill is the prompt. But there's a catch — every token counts. You prompt an AI to write a small function, and your score is the number of tokens in your prompt plus the AI's code. Lowest score wins. Fewer tokens means less to pay for and less context to manage, which is a real thing you will care about all semester.

How a hole works

  1. Read the challenge. Write a prompt that makes an AI produce the function — save it as prompt.txt.
  2. Paste the AI's answer as solution.py (just the function, nothing else).
  3. Score it: 
    python score.py 1 prompt.txt solution.py
    It runs the hidden tests and, only if they all pass, prints your token score.
  4. Report your group's score for each hole to the scoreboard on screen. Lowest total across the three holes wins.

Grab the scorer once and reuse it for all three holes: Download score.py. It counts tokens the same way for everyone, so groups are comparable. Precise wording shortens the prompt; a tidy function shortens the code — both lower your score.

Hole 1 — Reverse

Write rev(s) that returns the string s reversed.

rev("hello")  ==  "olleh"
rev("ab cd")  ==  "dc ba"
rev("")       ==  ""

The warm-up. See how few tokens a working prompt can be.

Hole 2 — Top word

Write top_word(text) that returns the most frequent word. Split on whitespace, compare in lowercase, and if two words tie, return the one that appears first.

top_word("the cat the dog")    ==  "the"
top_word("a b b a")            ==  "a"      # tie 2-2, "a" appears first
top_word("Hello hello WORLD")  ==  "hello"  # lowercased

Here a vague prompt fails the tests — the tie rule and the lowercasing have to be said. Precision is the game.

Hole 3 — Line stats

Write line_stats(path) that reads the text file at path and returns a tuple (number_of_lines, total_words, longest_line_length). Count lines with splitlines() (a trailing newline does not add an empty line).

# a file containing:
# hello world
# foo
# <blank line>
# longest line here now
line_stats(path)  ==  (4, 7, 21)

The biggest task — reading, then computing.

Chain bonus. Solve this one through your agent instead of by hand: give it a read_file tool and a compute tool, and make it call both in a single turn — read the file, then compute the stats. Show the two tool calls to an instructor for a bonus. If you have never chained two tool calls, this is the rung from Class 05 — sit with a group-mate who has.

The rule for AI today: the AI drives, you steer

Opposite of yesterday. You may have the AI write the whole function — that is the point. What you may not do is hand-write the code and pretend it was prompted, or count tokens by hand. Submit the real prompt you used and the real answer you got, and let score.py count. The honest game is the fun one.
